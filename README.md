# ecommerce-sql-analysis-2026
E-commerce data analysis using SQL

## Project Overview

This project analyzes e-commerce customer, order, product, and order item data using SQL.

The objective is to answer business-related questions and generate insights about customers, orders, products, sales, and purchasing behavior.

## Dataset

The project uses four main datasets:

- Customers
- Orders
- Order_Items
- Products

## Tools & Technologies

- SQL Server
- GitHub

## SQL Concepts Used

- SELECT and filtering
- GROUP BY and HAVING
- Aggregate functions
- INNER JOIN and LEFT JOIN
- CTEs
- Window functions
- Ranking functions
- CASE statements
- Business analysis queries

## Business Questions

The analysis includes questions such as:

- Who are the top customers based on number of orders?
- Which customers are repeat customers?
- What are the most frequently ordered products?
- What is the distribution of order status?
- Which products perform best within each category?
- How do customers and products contribute to overall sales?
- What are the running totals of orders?
- How are products ranked within each category?

## Project Files

- `SQLQuery1.sql` – SQL queries used for the analysis
- `customers.csv` – Customer data
- `orders.csv` – Order data
- `order_items.csv` – Order item details
- `products.csv` – Product information

## Key Skills Demonstrated

This project demonstrates practical SQL skills for data analyst roles, including data exploration, data validation, joins, aggregation, CTEs, window functions, ranking, and business-oriented analysis.
